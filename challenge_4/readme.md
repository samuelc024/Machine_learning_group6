# Challenge 4 — Reinforcement Learning (BC & GAIL) on Atari Venture (Group 6)

## What this is about
This folder contains the code and results for **ML Challenge 4**, focused on training an Artificial Intelligence agent to play the Atari 2600 game *Venture* using **Imitation Learning** and **Reinforcement Learning**.

- **Environment:** `ALE/Venture-v5` (Gymnasium with Atari Preprocessing).
- **Goal:** Train an agent to navigate dungeons, avoid/kill monsters, and collect treasures aggressively.
- **Models (Architecture):** Advantage Actor-Critic (A2C) combined with a Generative Adversarial Imitation Learning (GAIL) Discriminator.
- **Learning Methods:** Behavioral Cloning (BC) as a baseline, and GAIL with a hybrid reward system (adversarial style matching + native environment rewards).

The scripts are built as a **complete, reproducible pipeline**—from human gameplay recording to adversarial training and automated video evaluation.

## Contents
- `ver_experto.py` / `JugarVenture.py` — Pygame interface to record human demonstrations at 15 FPS.
- `merge_demos.py` — Utility to consolidate multiple `.npz` micro-game recordings into a master dataset.
- `train_bc.py` — **Behavioral Cloning** runner (Supervised Learning baseline).
- `train_gail.py` — **GAIL** runner (Adversarial Reinforcement Learning with A2C mathematical corrections and gradient clipping).
- `eval_gail.py` — Evaluation script that renders the agent's gameplay and saves high-quality MP4 videos.
- `src/models.py` — Neural network definitions (`AtariActorCritic` and `GAILDiscriminator`).
- `pyproject.toml` — Python dependencies and project metadata.

## The Learning Pipeline (What runs)
Our architecture follows a strictly defined 3-phase pipeline to ensure training stability and performance:

### 1) Human Intuition Capture (`merge_demos.py`)
- Takes raw `.npz` files containing human actions and 84x84 grayscale frame-stacked observations.
- Merges them into a unified `demos_humano.npz` dataset containing highly aggressive, treasure-seeking behavior.

### 2) Baseline Cloning (`train_bc.py`)
- Trains the `AtariActorCritic` model using standard Cross-Entropy Loss to mimic human keystrokes.
- Serves as the pre-trained weights for the GAIL Generator to prevent the "cold start" problem in Reinforcement Learning.
- Saves the initial weights as `bc_policy.pt`.

### 3) Adversarial Combat (`train_gail.py`)
- Pits the Generator (Agent) against a Discriminator (Detective). 
- **Memory Optimization:** Uses batched tensor sampling to prevent VRAM Out-of-Memory (OOM) errors.
- **Hybrid Reward System:** The agent receives a continuous reward for tricking the Discriminator (-log(1 - D(s))), and a massive discrete reward (+20.0) intercepted from the Atari emulator upon finding a treasure.
- **Stability:** Implements Advantage normalization (A2C correction), entropy bonuses for exploration, and strict Gradient Clipping (`max_norm=0.5`) to prevent NaN explosions upon receiving large hybrid rewards.

## Outputs and where to find them
Running the pipeline will generate the following artifacts:

- `demos_humano.npz` — The master dataset of human expert play.
- `bc_policy.pt` — The supervised learning baseline weights.
- `gail_long13_generator.pt` — The final Actor-Critic weights (The Agent).
- `gail_long13_discriminator.pt` — The final Discriminator weights.
- `videos_gail/` — A directory containing `.mp4` recordings of the agent during evaluation runs (generated by `eval_gail.py`).

python -m venv .venv

python group6/merge_demos.py --input-dir micro_demos --output demos_humano.npz

Notes / Reproducibility
The Atari environment runs in grayscale, scaled to 84x84 pixels, with a frame skip and frame stack of 4. This matches the DeepMind standard for RL.

If encountering moviepy or ffmpeg path issues during evaluation on Windows, ensure you are running the command using python -m group6.eval_gail or have the correct execution policies enabled.

Avoid running train_gail.py with render_mode="rgb_array" to prevent storage overflow; visual evaluation is strictly handled by eval_gail.py.
